## 1. Visual Theme & Atmosphere

학교 현장에서 교사가 매일 열어보는 실무 도구다. 화려함보다 신뢰감과 가독성이 우선이고, 데이터(표·등급컷·차트)가 주인공이어야 한다. 기존의 절제된 "공공기관 톤"은 이미 방향이 맞으므로 뒤집지 않는다 — 다만 토큰 일관성을 정리하고, 여백 리듬과 위계를 다듬어 "대충 만든 관공서 사이트"가 아니라 "차분하게 잘 정돈된 업무 도구"로 체감되게 만든다.

## 2. Color Palette & Roles

| 이름 | Hex | 역할 |
|---|---|---|
| Canvas | `#F7F8FA` | 페이지 배경 (기존 유지) |
| Surface | `#FFFFFF` | 카드·테이블·팝업 배경 |
| Primary | `#2C5282` | 액센트 — 버튼·강조·활성 탭 (기존 색 유지, 브랜드 보존) |
| Primary Dark | `#1A365D` | Hover/Active, 헤더 텍스트 |
| Ink | `#1A1A1A` | 본문 텍스트 (Pure Black 아님, 기존 유지) |
| Mute | `#666666` | 보조 텍스트 |
| Border | `#D9D9D9` | 구분선 |
| Success | `#2E7D32` / Warning `#EF6C00` / Danger `#C62828` | 상태 색 (기존 유지) |

**필수 규칙**: 액센트는 Primary 하나만 사용(이미 준수 중). Pure Black·보라 그래디언트 없음(이미 준수 중) — 색상 팔레트 자체는 변경하지 않고 **적용 일관성**만 교정한다.

## 3. Typography Rules

- Family: `Pretendard, -apple-system, ... sans-serif` (이미 적용됨, 유지)
- 표 제목(h4): `font-weight:700`, `margin-bottom:0.5rem`로 통일 (기존엔 화면마다 미세하게 다름)
- 본문/표 셀: `font-size:0.92rem`, `line-height:1.6`
- 헤드라인(h2): `letter-spacing:-0.01em`으로 살짝 타이트하게 — 공공기관 타이틀 특유의 밋밋함 완화
- 한국어 줄바꿈: 헤드라인·버튼 라벨에 `word-break: keep-all` 적용 (표 셀은 제외 — 좁은 셀에서 줄바꿈 필요)

## 4. Component Stylings

**Button (Primary — `.copy-btn`, `.action-btn`)**
- Default: `background: var(--primary-color)`, `color:#fff`, `border-radius:6px`
- Hover: `background: var(--primary-dark)`, `transform: translateY(-1px)`, 120ms ease
- Focus-visible: `outline: 2px solid var(--primary-color)`, `outline-offset:2px` (기존엔 focus 상태 없음 → 접근성 보완)
- Active: `transform: translateY(0)`
- Disabled: `opacity:0.5`, `cursor:not-allowed`

**Card / Table Wrapper (`.table-wrapper`, `.content-section`)**
- `background:#fff`, `border:1px solid var(--border-color)`, `border-radius:10px`
- 그림자는 `0 1px 3px rgba(15,23,42,0.06)`로 경량화 (기존 `rgba(0,0,0,0.2)`처럼 짙은 그림자는 제거 — 과한 입체감이 "공공기관 UI+AI 남용" 인상을 만듦)
- Hover는 인터랙티브 카드(탭 버튼 등)에만, 정적 데이터 카드엔 hover 이펙트 없음

**Input (등급컷 입력 등)**
- Default: `border:1px solid var(--border-color)`, `border-radius:4px`
- Focus: `border-color: var(--primary-color)`, `box-shadow:0 0 0 3px rgba(44,82,130,0.12)` (기존 0.15 알파 약간 낮춰 과하지 않게)
- Invalid: 기존 `.cut-invalid` 빨강 테두리 유지

**Modal (`#messagePopup`, `#loadingPopup`, `.modal-card`, `#ebsiProgressModal`)**
- `border-radius:12px` 통일 — 기존 `var(--radius)`가 미정의 토큰이라 실제로는 각진 모서리로 렌더링되던 버그를 `var(--border-radius)`로 교정
- `box-shadow: 0 12px 32px rgba(15,23,42,0.16)` (기존보다 부드럽고 넓게 퍼지는 그림자로 교체)

## 5. Layout Principles

- 컨테이너 최대 폭은 유지 (실무 도구라 표가 넓어야 하므로 `max-w` 강제는 적용하지 않음 — 데스크톱 실사용 맥락 우선)
- 섹션 내부 패딩을 `1.5rem → 1.75rem`으로 살짝 늘려 표/카드 사이 호흡감 확보
- `height:100vh` (설정 사이드바) → `height:100dvh`로 교체 (iOS 하단바 버그 방지)
- 반응형은 기존 브레이크포인트(`768px`) 유지, 표는 `overflow-x:auto`로 가로 스크롤 허용(실무 데이터 표는 컬럼 축약보다 스크롤이 안전)

## 6. Depth & Elevation

- 그림자를 3단계로 표준화: `--shadow-sm: 0 1px 3px rgba(15,23,42,0.06)` (카드/표) · `--shadow-md: 0 4px 12px rgba(15,23,42,0.10)` (드롭다운/토스트) · `--shadow-lg: 0 12px 32px rgba(15,23,42,0.16)` (모달)
- 기존에 화면마다 제각각이던 `rgba(0,0,0,0.05~0.3)` 그림자 값을 이 3단계로 수렴
- z-index: overlay=999, modal=1000-1001, settings-sidebar=10001 (기존 값 유지, 문서화만 추가)

## 7. Motion & Interaction

- MOTION=3 (차분함 우선, 실무 도구라 과한 모션 배제)
- 버튼/탭 전환: `transition: background-color .15s ease, transform .15s ease` 정도로 절제
- 로딩 스피너는 기존 유지 (기능적 모션이라 그대로)
- 새로 추가하는 모션 없음 — 있는 transition의 durations/easing만 일관되게 정리

## 8. Responsive Behavior

- 기존 브레이크포인트(`768px`) 유지
- 버튼 터치 영역 `--btn-height:34px` → 모바일에서는 최소 40px로 상향 (44px HIG엔 못 미치지만 데스크톱 실무 도구 특성상 절충)
- 표는 가로 스크롤 허용, 세로 스택 강제 변환은 하지 않음 (등급컷 표처럼 열이 의미를 가진 표는 스택하면 오히려 읽기 어려움)

## 9. Anti-Patterns (Project-Specific Banned)

- 기존 Primary 블루(`#2C5282`) 색상 자체를 바꾸지 않는다 (브랜드/보존 계약)
- 등급컷 입력 표의 `id`, `data-*` 속성, `onclick` 핸들러는 **1바이트도 변경 금지** (JS가 정확히 이 속성들을 읽어서 동작함)
- 공공기관 대상 도구이므로 유머러스하거나 마케팅적인 카피 추가 금지
- 화려한 대시보드 스타일(네온, 글래스모피즘, 과한 그림자)로 가지 않는다 — "차분한 실무 도구" 톤 유지가 핵심 요구사항
